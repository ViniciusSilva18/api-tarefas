## 🚀 Endpoints
```
GET    /tasks?page=1&limit=10&status=todo&priority=high
POST   /tasks
GET    /tasks/:id
PATCH  /tasks/:id
DELETE /tasks/:id
```

## 🛠️ Setup
```bash
npm install && npm run dev
```
